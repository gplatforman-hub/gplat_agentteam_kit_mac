# 예산 대비 실적

> 일을 시작하기 전에 workspace/memory/facts.md 를 읽어 내 이름·팀 이름·로고 글자·색 4개를 확인하고 그 값을 쓴다.

[이 스킬이 하는 일]
예산표와 지출 내역을 받아 항목별 예산 대비 실적표와 차이 설명을 만든다.

[Step 0 — 먼저 파일을 살핀다]
  예산표·지출 내역의 행 수 · 열 이름 · 기간 · 빈 칸 수 · 항목 이름이 서로 맞는지를 표로 보여준다.
  항목 이름이 두 파일에서 다르면(예: "교육비" / "교육훈련비") 짝을 지어 보여주고 확인을 받는다.

[계산 — 파이썬으로]
  항목 | 예산 | 실적 | 차이(실적−예산) | 집행률(실적÷예산)
  합계·차이·집행률은 가능하면 엑셀 수식으로 넣어, 숫자를 바꾸면 따라 바뀌게 한다.
  표 아래에 계산 식을 적는다. 원본 파일은 고치지 않는다.

[차이 설명]
  집행률이 가장 높은 셋과 가장 낮은 셋을 골라 "무엇이 · 얼마나 · 왜(내역에서 보이는 것만)"를 한 줄씩.
  이유가 내역에 없으면 "확인 필요".

[결과물]
workspace/결과물/<날짜>_<기간>_예산실적.xlsx   ← 시트1 실적표, 시트2 항목 짝 확인
workspace/결과물/<날짜>_<기간>_예산실적.md     ← 요약 세 줄 + 표 + 차이 설명 + 확인 필요

[절대 금지]
- 없는 예산·금액을 지어내지 않는다. 세무·회계 처리 판단은 하지 않고 담당 부서 확인을 권한다.
- 회사 실제 재무 파일을 받으면 "비식별 사본으로 해 주세요" 한 줄로 돌려준다.

[끝낼 때]
저장한 파일 경로와 '확인 필요' 항목만 모아서 알려 준다.
