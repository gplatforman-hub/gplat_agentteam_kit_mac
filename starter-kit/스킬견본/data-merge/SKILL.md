# 취합·검증

> 일을 시작하기 전에 workspace/memory/facts.md 를 읽어 내 이름·팀 이름·색 4개를 확인하고 그 값을 쓴다.

[이 스킬이 하는 일]
형식이 다른 여러 파일을 하나의 표로 합치고, 무엇을 맞췄고 무엇을 사람이 확인해야 하는지 검증 리포트를 만든다.

[Step 0 — 합치기 전에 살핀다]
  1. ⭐ 합칠 파일 또는 폴더
  2. 파일마다 행 수 · 열 이름 · 날짜 형식 · 금액 단위 · 빈 칸 · 중복 행 · 글자로 들어간 숫자를 표로 보여준다.
  3. 열 이름과 항목 이름(제품·거래처)을 하나로 맞출 **대응표**를 제안하고 확인을 받는다.
     기준 목록(제품 코드표 등)이 있으면 그것에 맞춘다. 없으면 묻는다.
  4. 단위를 무엇으로 맞출지 묻는다. 환율·환산 비율은 **내가 준 값만** 쓰고 결과에 적는다.
  → 대응표와 단위를 확인받기 전에는 합치지 않는다.

[합치기]
- 계산은 반드시 파이썬(pandas)으로 한다.
- 원본 파일 이름을 '출처' 열로 남긴다.
- 기간 밖 행 · 중복 행 · 빈 칸은 지우거나 채우지 않고 '검증 메모' 열에 표시한다.
- 원본 파일은 고치지 않는다. 결과는 새 파일로.

[결과물]
workspace/결과물/<날짜>_<주제>_취합.xlsx  ← 시트1 합친 표 · 시트2 항목별 합계 · 시트3 검증 리포트
workspace/결과물/<날짜>_<주제>_취합.md    ← 요약 세 줄 + 검증 리포트

[검증 리포트 — 세 칸]
| 맞춘 것 (대응표·단위·날짜) | 표시만 한 것 (중복·빈 칸·기간 밖) | 사람이 확인할 것 |

[검산 — 끝내기 전에 반드시]
출처별 합계를 원본에서 다시 계산해 "결과 | 다시 계산 | 일치" 표로 대조한다. 틀리면 고치기 전에 알린다.
