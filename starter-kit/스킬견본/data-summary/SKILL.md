# 엑셀·CSV 집계

> 일을 시작하기 전에 workspace/memory/facts.md 를 읽어 내 이름·팀 이름·로고 글자·색 4개를 확인하고 그 값을 쓴다.

[이 스킬이 하는 일]
엑셀·CSV 파일을 받아 묶고 세고 더해서, 표·차트·요약 세 줄로 만든다.

[Step 0 — 먼저 파일을 살핀다 (계산하기 전에)]
  파일 이름 · 시트 · 행 수 · 열 이름 · 빈 칸 수 · 중복 행 수를 표로 보여준다.
  날짜·숫자 열이 글자로 들어가 있으면 알려준다.
  → 무엇으로 묶을지 내가 말하지 않았으면 열 이름을 보고 후보 셋을 제안하고 고르게 한다.

[계산]
- 계산은 반드시 파이썬(pandas 또는 openpyxl)으로 한다. 손으로 어림하지 않는다.
- 결과 표 아래에 계산 식을 적는다. 예: 증감률 = (이번 달 − 지난달) ÷ 지난달
- 빈 칸은 0으로 채우지 않는다. 뺀 행 수를 따로 적는다.
- 원본 파일은 절대 고치지 않는다. 결과는 새 파일로.
- 합계·증감률은 가능하면 엑셀 수식으로 넣어, 숫자를 바꾸면 따라 바뀌게 한다.

[결과물]
workspace/결과물/<날짜>_<주제>_집계.xlsx   ← 시트1 결과 표, 시트2 원본 확인 표
workspace/결과물/<날짜>_<주제>_집계.png    ← 차트 1장 (비교는 막대, 추이는 선)
workspace/결과물/<날짜>_<주제>_집계.md     ← 요약 세 줄 + 표 + 계산 식 + 확인 필요

[검산 — 끝내기 전에 반드시]
결과 표의 숫자를 원본에서 다시 계산해 "결과 숫자 | 다시 계산한 숫자 | 일치" 표로 확인한다.

[요약 세 줄]
가장 큰 것 · 가장 많이 변한 것 · 눈여겨볼 것 (이상치·빈 달)

[절대 금지]
- 원본에 없는 달·값·목표치를 지어내지 않는다.
- 회사 실제 매출 파일을 받으면 "비식별로 바꾼 사본으로 해 주세요" 한 줄로 돌려준다.

[끝낼 때]
저장한 파일 경로와 '확인 필요' 항목만 모아서 알려 준다.
