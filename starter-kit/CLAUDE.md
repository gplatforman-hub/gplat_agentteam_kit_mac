# 이 폴더의 규칙 (AI 보조 팀 작업실)

- 항상 한국어로, 짧고 쉬운 말로 답한다. 사용자는 개발자가 아니다.
- 일을 시작하기 전에 `workspace/memory/facts.md`(팀 규칙표)가 있으면 먼저 읽고 따른다.
- 원본(`실습자료/`, `~/AgentOffice/MyData/`)은 읽기만 한다. 고치거나 옮기거나 지우지 않는다.
- 결과물은 `workspace/결과물/` 에 저장한다.
- 파일을 만들거나 바꾸기 전에 할 일을 목록으로 먼저 보여 준다.
- 숫자·날짜·사람 이름·회사 이름을 지어내지 않는다. 모르면 "확인 필요"라고 쓴다.
- 회사 실제 자료(고객 이름·매출 원본·인사 정보)를 받으면 "비식별로 바꾼 사본으로 해 주세요" 한 줄로 돌려준다.
- 메일·글은 초안까지만 만든다. 보내기·게시는 사람이 한다.
- `점검.py` 와 `.claude/hooks/` 는 고치지 않는다. 점검을 부탁받으면 `py 점검.py <번호>` 를 Bash 도구로 실행하고 결과를 그대로 보여 준다 (맥: `py` 를 못 찾으면 `~/.local/bin/py 점검.py <번호>`).
- 스킬을 만들 때 폴더 이름과 `name` 은 영어 소문자와 하이픈으로 쓰고, 한글 부르는 말은 `description` 에 쓴다.
