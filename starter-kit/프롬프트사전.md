# 프롬프트 사전 — 수업 뒤 내 업무에 바로 쓰는 문장 (부록 E)

**쓰는 법**: 대괄호 `[ ]` 안만 내 것으로 바꿉니다. 재료 파일은 비식별 사본으로 준비합니다.
처음에는 **가볍게**로 시작하고, 결과가 마음에 들면 **조건 넣어** → **끝까지 맡기기** 순서로 올라갑니다. 세 번 쓴 문장은 스킬로 저장하세요(P5).

> 🔒 메일과 글은 초안까지만 만듭니다. 보내기와 게시는 사람이 합니다.

## E1 · 보고서

### E1-a — 가볍게

```
[재료 파일] 을 읽고 A4 한 장 보고서 초안을 써 줘. 결론을 맨 앞에 두고, 재료에 없는 내용은 [확인 필요]로 표시해.
```

### E1-b — 조건 넣어

```
[재료 파일] 로 [팀장님] 께 올릴 보고서를 써 줘.
순서는 요약 세 줄 → 현황 표 → 이슈와 대응 → 결정이 필요한 것.
지연된 일은 숨기지 말고 이유와 새 기한을 같이 적어 줘. 시작 전에 목차부터 보여 줘.
```

### E1-c — 끝까지 맡기기

```
[재료 폴더] 의 파일을 모두 읽고 [월간] 보고서를 만들어 줘.
숫자는 파이썬으로 다시 계산해 대조표를 붙이고, 재료 사이에 숫자가 다르면 어느 파일이 어떻게 다른지 알려 줘.
workspace/결과물 에 내용(.md)과 인쇄용 한 장(.html)으로 저장해 줘.
```

## E2 · 메일

### E2-a — 가볍게

```
[받는 사람] 에게 보낼 메일 초안을 써 줘. 용건은 [용건]. 첫 줄에 용건을 쓰고 다섯 줄 안으로 줄여 줘. 보내지는 마.
```

### E2-b — 조건 넣어

```
아래 메일에 대한 회신 초안을 두 가지로 써 줘. 하나는 부드럽게, 하나는 분명하게.
내 입장은 [내 입장]. 내가 알려 주지 않은 약속·날짜·금액은 넣지 마.
---
[받은 메일 붙여넣기 — 이름·회사는 지운 사본]
```

### E2-c — 끝까지 맡기기

```
[메일 모음 파일] 을 읽고 답이 필요한 순서대로 표를 만들어 줘. 표: 보낸 사람(역할) | 용건 | 답 기한 | 내가 정할 것.
답이 필요한 건마다 회신 초안을 쓰고, 정보가 모자라면 초안에 [확인 필요]로 표시해 줘.
workspace/결과물 에 저장만 하고 보내지는 마.
```

## E3 · 회의 준비

### E3-a — 가볍게

```
[회의 주제] 회의의 안건을 세 개로 정리하고, 안건마다 정해야 할 것을 한 줄씩 적어 줘.
```

### E3-b — 조건 넣어

```
[지난 회의록 파일] 을 읽고 다음 회의 자료를 만들어 줘.
지난 할 일 중 끝난 것과 남은 것을 나누고, 남은 일은 담당·기한을 표로 적어 줘. 모르면 [확인 필요].
```

### E3-c — 끝까지 맡기기

```
[회의록 폴더] 의 최근 회의록을 모두 읽고, 여러 번 미뤄진 안건과 담당이 없는 일을 찾아 줘.
다음 회의 안건 순서와 각 안건의 시간 배분을 제안해 줘. 근거는 회의록 파일 이름과 함께 적어 줘.
```

## E4 · 엑셀·숫자

### E4-a — 가볍게

```
[파일] 을 살펴보고 행 수, 열 이름, 빈 칸, 중복 행을 표로 알려 줘. 아직 고치지는 마.
```

### E4-b — 조건 넣어

```
[파일] 을 [월별·담당별] 로 집계해서 새 엑셀로 저장해 줘. 합계와 증감률은 엑셀 수식으로 넣어 줘.
빈 칸은 0 으로 채우지 말고 뺀 행 수를 적어 줘. 원본은 고치지 마.
```

### E4-c — 끝까지 맡기기

```
[파일 두 개] 를 [공통 열] 기준으로 합쳐서 분석해 줘.
짝이 안 맞는 행은 따로 표로 빼고, 가장 눈에 띄는 사실 세 가지를 근거 숫자와 함께 적어 줘.
결과 숫자를 원본에서 다시 계산해 대조표까지 붙여 줘.
```

## E5 · 자료 조사

### E5-a — 가볍게

```
[문서 파일] 을 읽고 한 줄 결론과 핵심 세 가지로 요약해 줘. 숫자에는 쪽 번호를 붙여 줘.
```

### E5-b — 조건 넣어

```
[폴더] 의 자료로 [선택지 A·B·C] 를 비교해 줘. 비교 기준은 [비용·기간·위험].
표의 모든 숫자에 (파일 이름 p.쪽) 을 붙이고, 자료에 없는 칸은 [확인 필요]로 둬.
```

### E5-c — 끝까지 맡기기

```
[폴더] 의 문서를 두세 개씩 나눠 읽고 문서별 요약을 먼저 저장한 뒤, 요약을 합쳐 한 장 보고서를 써 줘.
문서끼리 다른 말을 하는 곳을 따로 표로 정리하고, 내가 정해야 할 것을 맨 끝에 적어 줘.
```

## E6 · 글 다듬기

### E6-a — 가볍게

```
아래 글을 뜻은 그대로 두고 더 짧고 분명하게 고쳐 줘. 바꾼 이유도 세 줄로 알려 줘.
---
[글 붙여넣기]
```

### E6-b — 조건 넣어

```
아래 글을 [임원 보고] 에 맞게 고쳐 줘. 결론을 첫 문장으로 올리고, "많이"·"빨리" 같은 말은 숫자나 날짜로 바꿔 줘.
숫자를 모르면 [확인 필요]로 표시해 줘.
---
[글 붙여넣기]
```

### E6-c — 끝까지 맡기기

```
[내 문서 세 개] 를 읽고 내 글의 공통 습관을 찾아 줘. 근거 문장도 같이 보여 줘.
그 습관으로 workspace/memory/문체가이드.md 초안을 만들고, 내가 확인한 뒤에 쓰도록 표시해 줘.
```

## E7 · 해외영업·고객 대응

### E7-a — 가볍게

```
아래 영문 메일을 한글로 요약하고, 상대가 묻는 것을 번호 붙여 목록으로 뽑아 줘. 답장은 아직 쓰지 마.
---
[메일 붙여넣기 — 회사명·이름·연락처는 지운 것]
```

### E7-b — 조건 넣어

```
아래 영문 메일에 답장 초안을 써 줘. 답은 [근거 문서] 에 있는 내용만 쓰고, 문서에 없는 것은 "We are confirming this" 로 두고 [확인 필요] 목록에 올려 줘.
가격·납기·보상은 쓰지 마. 영문 답장 아래에 한글 요약 세 줄을 붙여 줘.
---
[메일 붙여넣기]
```

### E7-c — 끝까지 맡기기

```
[문의 폴더] 의 메일을 모두 읽고 "질문 | 고객 | 근거 문서의 답 | 근거 위치 | 확인 필요" 표를 만들어 줘.
같은 질문이 두 번 이상 나오면 FAQ 후보로 따로 모으고, 기존 [FAQ 문서] 와 다른 답이 있으면 표시해 줘.
workspace/결과물/ 에 표(.xlsx)와 FAQ 개정안(.md)으로 저장해 줘. 메일은 보내지 마.
```

## E8 · 데이터 취합·검증

### E8-a — 가볍게

```
[파일 두세 개] 를 열어서 열 이름 · 행 수 · 날짜 형식 · 금액 단위 · 빈 칸 · 중복 행을 파일별로 표로 비교해 줘. 아직 합치지 마.
```

### E8-b — 조건 넣어

```
[폴더] 의 파일을 하나로 합쳐 줘. 계산은 파이썬으로 하고, 합치기 전에 열·항목 이름 대응표와 단위 맞추는 방법을 먼저 보여 줘.
중복·빈 칸·기간 밖 행은 지우지 말고 '검증 메모' 열에 표시해 줘. 원본은 고치지 마.
```

### E8-c — 끝까지 맡기기

```
[폴더] 의 [월간 실적] 파일을 합쳐 workspace/결과물/ 에 합친 표 · 항목별 합계 · 검증 리포트 세 시트짜리 엑셀로 저장해 줘.
검증 리포트는 "맞춘 것 | 표시만 한 것 | 사람이 확인할 것" 세 칸으로 쓰고, 출처별 합계를 원본에서 다시 계산해 대조표를 붙여 줘.
매달 할 일이니 끝나면 이 순서를 스킬로 저장할지 물어봐 줘.
```
