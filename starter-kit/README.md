# 내 AI 보조 팀 만들기 — 스타터킷 (직장인판)

이 폴더가 여러분의 **AI 보조 팀 사무실**이 될 자리입니다. 지금은 뼈대만 있고, 오늘 하루 동안 내용을 채웁니다.

- 공통 직원 5명 — **팀장(주간보고) · 회의록대리 · 데이터대리 · 문서대리 · 조사대리** 가 어느 직무든 반복하는 일을 맡습니다.
- 직무 트랙 직원 1명 — 영업 · 마케팅 · 인사 · 기획 · 관리 중 내 직무 하나를 골라 6번째로 데려옵니다.
- 🔒 **회사 자료는 넣지 않습니다.** 연습은 `실습자료/` 의 가상 회사(가온리빙)로, 내 양식은 이름·숫자를 지운 사본으로 합니다.

## 이 키트는 맥(macOS)용입니다

윈도우 교안을 그대로 따라가되, 아래 네 가지만 바꿔 읽으면 됩니다.

| 교안(윈도우)에 나오는 것 | 맥에서는 |
|---|---|
| `○○.command` 더블클릭 | 같은 이름의 **`○○.command`** 를 Finder 에서 더블클릭 (터미널이 열립니다) |
| 터미널 · 터미널 창 · 터미널 창 | **터미널** 앱 (Spotlight `⌘ + Space` → 「터미널」) |
| `C:\AgentOffice\01_KIT\starter-kit` · 경로의 `\` | **`~/AgentOffice/01_KIT/starter-kit`** · 경로는 `/` |
| 붙여넣기 = ⌘ + V · `⌘ + C/V/P` · Enter | **`⌘ + V`** · `⌘ + C/V/P` · **return** |

`py -3 …`, `py 점검.py 3` 같은 명령은 **맥에서도 똑같이** 씁니다 (환경점검이 맥용 `py` 를 만들어 둡니다).

## 가장 쉬운 길 — 명령어 한 줄 설치

**터미널**을 열고(Spotlight `⌘ + Space` → 「터미널」 → return, 관리자 비밀번호 필요 없음) 아래 한 줄을 붙여넣고(`⌘ + V`) return.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gplatforman-hub/gplat_agentteam_kit_mac/main/install.sh)"
```

이 한 줄이 스타터킷을 받아 `~/AgentOffice/01_KIT/starter-kit` 에 설치하고, 환경점검까지 이어서 돌립니다.
같이 만들어지는 **`~/AgentOffice/MyData/`** 에 내 보고서 3개·회의록 3개(비식별 사본)를 수업 전에 넣어 두세요 (아래).
프로그램은 없으면 **묻지 않고** 깔립니다 — Git(「명령어 도구 설치」 창이 뜨면 **설치** 누르기), Node.js 22, Claude Code.
**Python 은 수업용 3.14 를 따로** 깝니다(`~/AgentOffice/.venv`). 맥에 원래 있는 파이썬은 건드리지 않습니다.
파이썬 꾸러미 설치·확인까지 이어서 합니다. 사람이 할 일은 **설치 창의 「설치」 와 로그인**뿐입니다.
설치 중에는 슬랙 열쇠를 묻지 않습니다 — 교안 「슬랙 ①②」로 열쇠를 받은 뒤 **`슬랙열쇠_넣기.command`** 로 넣습니다. 인터넷이 켜져 있어야 합니다.

> `curl … | bash` 가 아니라 `/bin/bash -c "$(curl …)"` 인 이유: 파이프로 넘기면 키보드 입력 자리를 다운로드가 차지해서 로그인·열쇠 입력을 받을 수 없습니다.

3. 프로그램이 아래 표준 위치를 만들고 가벼운 스타터킷을 복사합니다.


기존 설치가 있으면 덮어쓰지 않으며, 설치 후 Finder 와 환경점검을 이어서 열어줍니다.

## 시작 전에 — 맥이 잠들지 않게

직원들이 일하는 **서버는 내 맥 안에서 돕니다.** **맥이 잠들면 직원도 같이 잠듭니다.** 슬랙에 말을 걸어도 아무도 대답하지 않습니다.

- 자동 실행되는 서버는 `caffeinate` 로 감싸 두어서, **전원이 연결돼 있으면** 서버 때문에 맥이 스스로 잠들지 않습니다.
- **덮개를 닫으면 잠듭니다** — 수업·업무 중에는 덮개를 열어 두세요 (외부 모니터를 연결해 쓰는 경우는 예외).
- 화면 꺼짐·화면 보호기는 그대로 두셔도 됩니다.
- 더 확실하게: **시스템 설정 → 배터리 → 옵션 → 「전원 어댑터 연결 시 디스플레이가 꺼져 있을 때 자동으로 잠자기 방지」** 켜기 (데스크톱 맥은 **시스템 설정 → 에너지**).
- `py 점검.py 8` 이 이 설정을 확인합니다 — `맥이 잠들지 않는다` 줄

## 내 양식 미리 넣기 — `~/AgentOffice/MyData/`

설치가 이 폴더를 만들어 둡니다. 부록 A(내 양식)에서 직원이 **내 보고서 구성·말투**를 여기서 배웁니다.
**수업 전날까지** 넣어 두면 당일이 편합니다. 없는 칸은 비워 두어도 수업은 진행됩니다.

> 🔒 **회사 원본을 그대로 넣지 마세요.** 사본을 만들어 회사 이름·사람 이름·고객사·금액을 `○○` 로 지운 뒤 넣습니다.
> 회사 규정상 사본도 가져올 수 없으면 **빈 양식(제목과 항목 이름만)** 을 손으로 적어 넣으세요.

| 폴더 | 넣을 것 | 개수 |
|---|---|---|
| `MyData/Report/` (보고서) | 내가 쓴 주간보고·업무보고 (docx·pptx·pdf·hwp·txt) | **3개** |
| `MyData/Minutes/` (회의록) | 내가 정리한 회의록 | **3개** |
| `MyData/Track/` (직무 문서) | (선택) 제안서·블로그 글·안내문·기획서·비용표 중 내 직무 것 | 3개 |
| `MyData/Skill/` (내 스킬) | (선택) **이미 쓰시던** 스킬 문서 `SKILL.md` | 있는 만큼 |

**`Skill` 칸은 이미 클로드를 써 오신 분만** 채우면 됩니다. 넣어 두면 부록 A 에서 그 스킬이 **그 일의 정본**이 되고, 수업에서 만든 뼈대 스킬은 `_보관` 으로 물러납니다. 처음이시면 비워 두세요 — 수업에서 처음부터 만듭니다.

폴더 이름이 영문인 것은 프로그램이 한글 경로에서 막히는 일을 없애기 위해서입니다. 폴더 안의 `여기에_넣으세요.txt` 에 같은 내용이 적혀 있습니다. 환경점검 「선택」 항목에 몇 개 들어갔는지 표시됩니다.

## 합격 판정 받는 법

모듈이 끝날 때마다 Code 탭에서 클로드에게 **"`py 점검.py 3` 실행하고 결과 보여 줘"** 라고 합니다. **점검 번호 = 모듈 번호**입니다.

```
py 점검.py 0     ← 출발선 (설치 직후)
py 점검.py 2~8   ← 각 모듈이 끝났을 때
py 점검.py 9     ← 전체
py 점검.py 10    ← 부록 A 내 양식
```

✅ 가 전부 켜지면 다음으로 넘어갑니다. ❌ 가 있으면 **그 줄만** 고치면 돼요.
`py` 가 안 먹으면 Claude 앱을 완전히 종료(⌘ + Q)했다 켜거나 `~/.local/bin/py -3 점검.py 3` 로 해보세요.

**`점검.py` 는 고치지 마세요.** 여러분이 만든 게 규격에 맞는지 보는 채점표입니다.

새 PC에서 복원할 때는 깨끗한 스타터킷을 먼저 설치하고 슬랙 서버를 끈 뒤,

슬랙 `.env`·메일 `.env`와 구글·네이버 로그인은 보안상 백업되지 않으므로 새 PC에서 다시 설정합니다.

## 직원이 한 일은 자동으로 남고, 지우는 일은 꼭 묻습니다

스타터킷에 **안전장치**가 들어 있습니다 (`.claude/settings.json` + `.claude/hooks/`). 켜거나 설정할 것은 없습니다.

| 무엇 | 어떻게 |
|---|---|
| 자동 기록 | 내가 친 명령·직원이 만들고 고친 파일이 `workspace/기록/작업기록_<날짜>.md` 에 한 줄씩 남습니다 |
| 자동 저장 | 직원이 답을 마칠 때마다 git 에 자동 저장 지점이 생깁니다 (모듈 1 카드 P1-c 의 `git init` 이후). `git log --oneline` 으로 봅니다 |
| 삭제·덮어쓰기 확인 | 파일 삭제 · 기존 파일 덮어쓰기 · 직원/스킬/팀 규약 수정 · `git checkout`류는 실행 전 **확인 창**이 뜹니다. 고르기 전엔 실행되지 않습니다 |
| 못 고치는 것 | `점검.py` · `.claude/settings.json` · `.claude/hooks/` — 직원이 수정하려 하면 막힙니다 |
| 슬랙 | 확인 창을 띄울 곳이 없어 삭제·덮어쓰기를 **막고** "터미널에서 진행해 주세요"라고 답합니다. 고장이 아닙니다 |

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| `py` 를 모르는 명령어래요 (`command not found`) | 환경점검.command 를 다시 실행하고, 터미널 창을 **새로** 엽니다. 그래도 안 되면 `~/.local/bin/py -3 점검.py 0` |
| 더블클릭했더니 「확인되지 않은 개발자」 | 파일을 **control + 클릭 → 열기 → 열기** (한 번만) |
| 더블클릭했더니 텍스트 편집기로 열려요 | 실행 권한이 빠진 것. 터미널에 `chmod +x ~/AgentOffice/01_KIT/starter-kit/*.command` |
| AI가 엉뚱한 파일을 고쳤어요 | 클로드에게 "아까 저장 지점으로 되돌려 줘" — git 저장 지점에서 되살립니다 |
| ❌ 가 안 없어져요 | 카드를 한 번 더 그대로 붙여넣으세요. 덮어씁니다 |
