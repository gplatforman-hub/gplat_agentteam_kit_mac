# 네이버 캘린더 (선택)

직원(Code 탭·슬랙)이 **내 네이버 캘린더 일정을 보고, 내가 승인한 일정만 넣게** 합니다.
구글 캘린더는 커넥터로 따로 연결합니다 — 이 폴더는 네이버 캘린더 전용입니다.

## 연결 (처음 한 번)

1. 네이버 → 내정보 → 보안설정 → **2단계 인증** 켜기
2. 같은 화면 「2단계 인증 관리」 → **애플리케이션 비밀번호** → 종류 「직접 입력」 → 생성 (12자리)
   - 메일 연결에 쓴 네이버 앱 비밀번호가 있으면 그것을 같이 써도 됩니다
3. 스타터킷 맨 위의 **`캘린더_연결.command`** 더블클릭
   - 메일을 네이버로 연결해 두었으면 「같이 쓸까요?」 → `y`
   - 아니면 아이디와 앱 비밀번호(별표로 가려짐)를 넣습니다
4. `OK: 네이버 캘린더 … — 캘린더 N개 …` 가 나오면 끝. 이때 직원용 스킬도 `.claude/skills/naver-calendar/` 에 자동으로 들어갑니다
5. Code 탭은 **새 세션**, 슬랙은 **새 대화** 를 보낸 뒤부터 씁니다

다른 계정으로 바꾸려면 `캘린더_연결.command` 을 다시 실행해 「바꿀까요?」 에 `y`.

## 도구

| 파일 | 하는 일 |
|---|---|
| `cal_check.py` | 로그인 → 캘린더 목록 → 이번 주 일정 수 (읽기만). `--detail` 이면 일정 제목까지 |
| `cal_read.py` | 일정 보기. `--today` · `--days N` · `--from 날짜 --to 날짜` · `--calendar 이름` · `--json` |
| `cal_add.py` | 일정 하나 넣기. **`--approved` 가 없으면 미리보기만** 합니다 |
| `connect.sh` | `캘린더_연결.command` 가 부르는 연결 창 |
| `skill/SKILL.md` | 직원용 스킬 원본 (연결에 성공하면 `.claude/skills/` 로 복사됨) |

고치기·지우기 도구는 일부러 없습니다. 사람이 네이버 캘린더 앱에서 합니다.

## 안 될 때

| 화면 | 할 일 |
|---|---|
| `로그인이 거절됐습니다` | 평소 비밀번호가 아니라 **애플리케이션 비밀번호** 인지 확인. 새로 만들어 `캘린더_연결.command` 다시 실행 |
| `캘린더 서버에 닿지 않습니다` | 인터넷·회사 방화벽 확인 |
| `.env 가 아직 없습니다` | `캘린더_연결.command` 실행 |

🔒 `naver-calendar/.env` 는 비밀번호와 같습니다. 남에게 주거나 캡처하지 마세요 (`.gitignore` 에 있어 저장소에는 올라가지 않습니다).
