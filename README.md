# gplatform AI 에이전트팀 (직장인판) — 스타터킷

「에이전트팀 만들기 과정 · 직장인판」 수강생용 스타터킷입니다. 내 반복 업무(주간보고 · 회의록 · 데이터 집계 · 메일 · 조사)를 덜어 줄
**AI 보조 팀 5명**에, 내 직무(영업 · 마케팅 · 인사 · 기획 · 관리) 직원 1명을 더해 하루 만에 만듭니다.
회사 자료 없이 **가상 회사 실습자료**로 연습하고, 개인 PC 에 설치합니다.

**맥(macOS)용**입니다. 윈도우는 `gplat_agentteam_kit` 저장소를 쓰세요.
프로그램을 내려받아 설치하는 게 아니라, **명령어 한 줄**로 설치합니다.

## 설치 (한 줄)

1. **터미널**을 엽니다 — `⌘ + Space` → 「터미널」 → return. (관리자 비밀번호 필요 없음)
2. 아래 한 줄을 붙여넣고(`⌘ + V`) return.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gplatforman-hub/gplat_agentteam_kit_mac/main/install.sh)"
```

## 이 한 줄이 하는 일

| 단계 | 내용 | 걸리는 시간 |
|---|---|---|
| 1 | 깃허브에서 스타터킷을 받는다 (`node_modules`·비밀키 없음) | 수 초 |
| 2 | `~/AgentOffice/01_KIT/starter-kit` 에 표준 설치한다. `~/AgentOffice/MyData/` 도 같이 만든다 | 수 초 |
| 3 | 환경점검을 이어서 돌린다 — Git(Xcode 명령어 도구)·Node.js 22·Python 3.14(uv)·Claude Code 가 없으면 **관리자 권한 없이** 설치 | 없는 것에 따라 몇 분 |

기존 설치가 있으면 덮어쓰지 않습니다. 인터넷이 켜져 있어야 합니다.
「명령어 도구 설치」 창이 뜨면 **설치**를 누르세요 (Git).

## 설치 후

- `~/AgentOffice/01_KIT/starter-kit/README.md` — 폴더 설명, **윈도우 교안을 맥에서 읽는 법**(표 한 장)
- `~/AgentOffice/MyData/` — **내 보고서 3개·회의록 3개(비식별 사본)** 를 수업 전에 넣어 두는 곳 (`Report/` 보고서 · `Minutes/` 회의록 · `Track/` 직무 문서 · `Skill/` 내 스킬)
- `프롬프트카드.md` — 강의장에서 모듈 0~6 순서대로
- 교안의 `○○.bat` 은 맥에서 같은 이름의 **`○○.command`** 입니다 (Finder 에서 더블클릭)

## 이 저장소에 없는 것

`.env`(슬랙 열쇠), 로그인 상태, `node_modules`, 캐시·로그는 들어 있지 않습니다. 보안상 정상입니다.
